# Product Specs

This directory holds behavior-level specs for user-facing workflows and future UI surfaces.

Current specs:

- `docs/product-specs/lantern.md`: generated first-pass product spec for `Lantern`
- `docs/product-specs/cli-contract.md`: first-milestone CLI command, flag, endpoint, output, and exit-code contract
- `docs/product-specs/output-policy.md`: shared human output, JSON ordering, redaction, truncation, and artifact output policy
- `docs/headless-chromium.md`: operator setup guide for exposing a local Chromium CDP endpoint without making Lantern own browser lifecycle
- `docs/authenticated-browser-testing.md`: operator workflow and safety checklist for dedicated logged-in Chromium profiles
