The programme's implemented contracts are qualified within the declared local
Chromium scope. The paired agent comparison is a case study of five tasks per
CLI, not a general ranking, latency benchmark or statistical superiority claim.
The exact evaluated inputs, equivalent capsules, agent reports, independent truth
summaries and artefact hashes accompany the [comparison report](comparative-ui.md).

The persistent authenticated-profile plan remains active and separate. Retained
limitations include hardware support, broader platform/runtime coverage,
application-specific design judgement, non-atomic capture correlation and
historical/future events outside bounded observations. Final independent review,
CI, landing, merged-head validation and installation identities belong in the
terminal pull-request evidence rather than a recursive closeout commit.
